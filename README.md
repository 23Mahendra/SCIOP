# SCIOP — SCI Open Innovation Platform

SCIOP is an open network concept for connecting people, skills, ideas, projects, businesses and opportunities across domains.

## Current starter
- Responsive landing page for desktop and mobile
- Platform overview, domain categories and how-it-works sections
- Introductory registration form UI
- Form prepares a copyable introduction locally in the browser

## Current limitations
The form does not submit or persist registrations. Authentication, a database, member profiles, opportunity listings, messaging and moderation still need to be implemented and tested before this can be treated as a live platform.

## Run locally
Open `index.html` in a browser, or serve the repository with any static web server.

## Deploy
This static starter can be hosted using GitHub Pages or another static hosting provider. A real registration system requires a backend/database and appropriate privacy/security controls.
